# SmartGate (Flutter)
1. `flutter create --org com.smartgate smartgate`   (creates android/ios folders)
2. Copy `lib/`, `assets/` and `pubspec.yaml` from this folder into that new project (replace existing).
3. `flutter pub get`
4. Connect phone (USB debugging on) and run: `flutter run`
5. APK for sharing: `flutter build apk --release`
   -> build/app/outputs/flutter-apk/app-release.apk
